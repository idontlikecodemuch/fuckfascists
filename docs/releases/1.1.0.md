# FCK 1.1.0 (Build 9)

Release version for the August 2026 update. Repository metadata is aligned to
`1.1.0`, iOS build `9`, and Android version code `9`.

## App Store — What’s New

Fresh records. Better timing. Clearer scans.

• FEC data rebuilt August 20, 2026 across the 2016–2026 election cycles, including refreshed presidential inaugural filings.

• Expanded and rechecked coverage for 754 companies and organizations and 1,091 donor and executive records.

• Added Cursor, Google Workspace, and Microsoft 365 to Track.

• Scorecard drops are now more genuinely unpredictable—down to the minute—while still arriving at the same moment for everyone within the Friday/Saturday window.

• Added clearer “dropping soon” handling when a new week begins before the previous week’s scorecard arrives.

• Rebuilt UPC scanner notices with product-specific results, parent-company context, app-style icons, and consistent repeat-scan behavior.

• Improved background data refreshes while preserving bundled, offline-first data.

• Fixed stale lookup results, missing entity coverage, and beta tools appearing when they shouldn’t.

No accounts. No tracking. Your activity stays on your device.

## Internal release record

### Data

- Final bundled data snapshot date: `2026-08-20`.
- Rehydrated all six supported FEC cycles: `2016`, `2018`, `2020`, `2022`, `2024`, and `2026`.
- Refreshed Form 13 presidential inaugural records for the 2017, 2021, and 2025 inaugural committees with replacement semantics to prevent double-counting.
- Bundled `754` live entities; `239` have confirmed committee IDs and donation summaries.
- Bundled `1,091` people with `1,091/1,091` hydration coverage.
- Rechecked company/person relationships and applied current ownership, executive, and historical-role corrections.
- Added Cursor, Google Workspace, and Microsoft 365 as opt-in Track platforms.
- Repaired runtime validation that had silently omitted 22 founder/owner-led entities.

### Runtime freshness and durability

- Restored the local → public Git bundle → live FEC fallback order.
- Rejects stale or suspiciously partial remote payloads instead of downgrading newer bundled data.
- New curated data supersedes older lookup-cache records.
- Falls back to stale curated totals when live FEC is unavailable rather than presenting blank records.
- Uses FEC/data.gov’s public, tightly rate-limited `DEMO_KEY` only for rare last-resort live lookups.
- Added a dismissible, per-version “NEW FILES ON DECK” App Store update notice; every failure path remains non-blocking.

### Scorecard

- Replaced correlated hourly scheduling with the synchronized `ff-drop-v2` minute-level sequence.
- Every install computes the same absolute drop moment in the Friday 6:00pm–Saturday 4:00pm America/New_York window.
- Handles Eastern daylight-saving transitions and keeps adjacent weekly drops at least 90 minutes apart.
- Added the Saturday rollover bridge: `LAST WEEK’S SCORECARD / DROPPING SOON` plus a clearly labeled `NEW WEEK` slate.

### Scan and beta polish

- Added four structured UPC toast states with distinct icons and precise product/parent-company copy.
- Product-found notices now separate the product name from the unmatched company candidate.
- Preserves `not_in_database` in the negative barcode cache so repeat scans stay truthful.
- Toasts are compact, non-blocking, dismissible, and auto-dismiss after six seconds.
- Beta state now uses a device-only key, ignores the legacy migratable state, and requires seven taps plus explicit confirmation.

### Verification

- Full Jest suite: `48` suites / `505` tests passing.
- TypeScript: clean.
- iPhone 17 Pro / iOS 26.5 simulator build: zero errors.
- UPC visual captures: `tools/screenshots/upc-toasts/`.
- Chrome, Firefox, Edge, and Safari extension packages rebuilt against the refreshed data.
